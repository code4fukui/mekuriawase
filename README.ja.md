# mekuriawase

日本の観光オープンデータを使用した神経衰弱ゲームです。カードをめくって観光地のペアを見つけると、その名前と写真が現れます。


![観光地の画像が示された、いくつかのカードがめくられているmekuriawaseのゲーム盤のスクリーンショット。](https://fukuno.jig.jp/2014/mekuriawaseodp.jpg)


## デモ

ブラウザ上でゲームをプレイできます: **https://github.com/code4fukui/mekuriawase

## 特徴

-   **メモリーゲーム:** 実際の観光地の画像と名前を使用した、クラシックなカード合わせ（神経衰弱）ゲームです。
-   **動的なデータ:** ライブのオープンデータソースから直接データを取得し、様々な観光地を提示します。
-   **ランダムな配置:** ゲーム開始時にカードの配置がシャッフルされます。
-   **場所の検索:** ペアが揃うと「ココに行く」ボタンが表示され、新しいタブでその場所の地図が開きます。
-   **タイムチャレンジ:** すべてのペアを揃えると「クリアタイム」が表示されます。

## 遊び方

1.  [デモURL](https://code4fukui.github.io/mekuriawase/) を開きます。
2.  任意の2枚のカードをクリックしてめくり、一致するか確認します。
3.  カードが一致した場合は表向きのままになります。一致しない場合は裏返ります。
4.  すべてのペアを見つけるまで続けます。
5.  「リトライ！」ボタンをクリックすると、新しくシャッフルされたカードで新しいゲームが始まります。

## データソース

このプロジェクトは、[Open Data Platform (ODP)](https://odp.jig.jp/) のSPARQLエンドポイントを使用して、日本の公共の観光スポットに関するデータを取得しています。
